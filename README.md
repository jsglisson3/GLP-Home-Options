# GLP Home Options — website

New website for **GLP Home Options** (Joey & Ethan), Chattanooga / Hixson, TN.

- `index.html` — the site. One self-contained file (images are embedded), so hosting it is just serving this file.
- `PICKUP.md` — where the work stands, everything learned from the current site and Facebook, and the next steps. **Start here when picking the project back up.**
- `research/` — source photos and the previous handoff notes. Not used by the page directly.

> Status: **working draft** for Joey's review. It is set to `noindex` so search engines skip this preview copy. Not ready to replace glphomeoptions.com yet. See `PICKUP.md` ("Before launch").

## Hosting on GitHub Pages

Same setup as FOTCL (`github.com/jsglisson3/FOTCL`, `.nojekyll` included):

1. Open `Documents\GLP-Home-Options` in VS Code → **Source Control** → **Initialize Repository** → commit → **Publish Branch** → choose **public** → name `GLP-Home-Options`.
2. On GitHub: **github.com/jsglisson3/GLP-Home-Options → Settings → Pages → Deploy from a branch → `main` / `(root)` → Save**.
3. About a minute later it's live at **https://jsglisson3.github.io/GLP-Home-Options/**

Every later push to `main` updates the live site automatically.
